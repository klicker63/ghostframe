# Technical article outline

## Working title
An AI agent release is a versioned permission decision

## Audience
AI product founders preparing an agent for production, Engineering teams integrating tool-using agents, Security teams reviewing agent authority and evidence

## Thesis
Teams can give AI agents consequential tools and permissions without a version-bound record of what was tested, what was allowed, and who approved release.

## Sections

1. Why agent names and model names are not release identities
2. Define the exact behavior-shaping configuration
3. Inventory tools at operation level
4. Separate model instructions from enforceable permissions
5. Bind human approval to exact consequential actions
6. Preserve secret-safe behavioral evidence
7. Define material-change invalidation before release
8. Use a Permission Envelope as the review boundary
9. Run hostile scenarios against the release candidate
10. Keep release authority with an accountable person
