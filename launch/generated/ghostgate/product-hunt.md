# Product Hunt listing

## Name
GhostGate Agent Release Readiness Check

## Tagline
One exact agent version. One tested configuration. One reviewable release record.

## Description
A no-login, browser-local self-assessment that identifies control gaps and generates a sample Permission Envelope.

Teams can give AI agents consequential tools and permissions without a version-bound record of what was tested, what was allowed, and who approved release.

Use the free tool to identify priority control gaps and move toward a clearly scoped independent assessment. Test one exact AI agent version against its intended tools, permissions, policies, and agreed hostile scenarios, then deliver a human-reviewed release decision and version-bound evidence package.

## Approved facts
- The free readiness check runs locally in the browser and requires no login.
- The Agent Release Check covers one exact agent version and one tested configuration.
- The fixed scope includes up to 20 agreed scenarios and one same-scope remediation retest.
- Deliverables include a human-reviewed release verdict, Permission Envelope, and version-bound evidence package.
- The fixed price is $5,000 USD with 50% at kickoff and 50% at delivery.

## Maker comment
We built this because release conversations about AI agents often begin after tool access has already become consequential. The tool is intentionally no-login and browser-local. We would value specific feedback on missing controls, confusing language, and whether the generated boundary is useful to a release owner.
