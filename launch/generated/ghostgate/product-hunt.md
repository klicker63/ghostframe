# Product Hunt listing

## Name

GhostGate Agent Release Readiness Check

## Tagline

Find release-control gaps before a tool-using AI agent reaches production.

## Description

GhostGate is a free, no-login self-assessment for teams defining an AI agent’s release boundary.

Describe one exact agent version, select its capabilities, and work through 15 control questions. The deterministic result shows a readiness category, dimension-level results, three priority gaps, suggested restrictions, and a sample Permission Envelope.

The assessment, scoring, and output generation run in the browser. Assessment answers and the generated Permission Envelope are not sent to GhostFrame.

The result is a planning aid—not certification, a safety guarantee, or evidence that independent testing has occurred.

Try the free tool: https://www.ghostframestudios.com/tools/agent-release-readiness/?utm_source=ghostframe&utm_medium=organic&utm_campaign=ghostgate-launch-v01&utm_content=product-hunt

## Maker comment

I built this because agent release discussions often start with a product name and a list of features, rather than the exact version, operations, identities, permissions, and approval gates being authorized.

I wanted the free tool to be useful without an account or sales conversation, so the assessment and result stay in the browser. It deliberately stops short of claiming that a checklist can verify an implementation or prove an agent safe.

If you try it, I would value specific feedback on missing controls, confusing answer choices, capability weighting, and whether the Permission Envelope is useful to a release owner.

## Optional reply if someone asks about independent testing

The free tool is a self-assessment. The separate GhostGate Agent Release Check is a $5,000 USD fixed-scope, human-reviewed assessment of one exact version and tested configuration, with up to 20 agreed scenarios and one same-version, same-scope remediation retest.
