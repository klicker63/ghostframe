## GhostGate Agent Release Check

One exact agent version. One tested configuration. One reviewable release record.

Test one exact AI agent version against its intended tools, permissions, policies, and agreed hostile scenarios, then deliver a human-reviewed release decision and version-bound evidence package.

### Fixed scope
- One AI agent
- One exact agent version or immutable build
- One test environment or supported adapter
- One tool and permission configuration
- One policy baseline
- Up to 20 agreed hostile, misuse, permission-boundary, and behavioral scenarios
- One same-version and same-scope remediation retest

### Evidence delivered
- Agent Trust Report
- Pass, Conditional Pass, or Block release verdict for the tested configuration
- Permission Envelope in JSON and YAML
- Behavioral evidence and scenario coverage summary
- Version-bound signed attestation
- Downloadable evidence bundle

### Important limits
- No guarantee of safety or complete scenario coverage
- No compliance certification or legal opinion
- No production monitoring or production interception unless separately contracted
- No assessment transfer to materially changed versions
