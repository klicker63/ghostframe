## GhostGate Agent Release Readiness Check

Before a tool-using AI agent reaches production, define the exact version, tools, identities, permissions, approval gates, data boundaries, and invalidation triggers being authorized.

The free GhostGate readiness check is a no-login, browser-local self-assessment. It uses 15 deterministic control questions to identify priority gaps and generate a sample Permission Envelope in JSON and YAML. Assessment answers are not sent to GhostFrame.

The output is a planning artifact—not certification, a safety guarantee, or evidence that independent testing has occurred.

[Assess an Agent](https://www.ghostframestudios.com/tools/agent-release-readiness/)

## GhostGate Agent Release Check

The separate paid Release Check is a human-reviewed, fixed-scope assessment of one exact agent version and tested configuration.

### Fixed scope

- One AI agent
- One exact agent version or immutable build
- One test environment or supported adapter
- One tool and permission configuration
- One policy baseline
- Up to 20 agreed hostile, misuse, permission-boundary, and behavioral scenarios
- One same-version, same-scope remediation retest

### Evidence delivered

- Agent Trust Report
- Pass, Conditional Pass, or Block release verdict for the tested configuration
- Permission Envelope in JSON and YAML
- Behavioral evidence and scenario coverage summary
- Version-bound signed attestation
- Downloadable evidence bundle

### Important limits

- No guarantee of safety or complete scenario coverage
- No compliance certification or legal opinion
- No production monitoring or production interception unless separately contracted
- No assessment transfer to materially changed versions
