# 90-second demo script

**0–10 seconds — Boundary**
“Before this agent receives production tools or credentials, we need to know exactly what is being authorized.” Show the no-login introduction and safety warning.

**10–25 seconds — Profile**
Enter a non-sensitive agent label, immutable version, environment, and intended capabilities. Explain that these values remain local.

**25–50 seconds — Controls**
Move through representative questions on authority, approvals, version immutability, permission enforcement, and adversarial testing. Show visible progress and the full maturity scale.

**50–70 seconds — Result**
Reveal the readiness category, eight dimension results, and three highest-priority gaps. Emphasize that this is a self-assessment, not certification.

**70–82 seconds — Permission Envelope**
Copy the generated JSON and YAML; point out tools, prohibited operations, identities, data boundaries, approvals, limits, logging, and invalidation triggers.

**82–90 seconds — Next step**
“Use the result for internal planning. If the exact release needs independent testing and version-bound evidence, request GhostGate Agent Release Check.”
