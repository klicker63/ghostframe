01 / The answer

Trust the version you reviewed—not the name on the agent.

Organizations need to know whether a particular combination of code, model, prompt, tools, identities, policy, memory, and dependencies may enter a particular production environment.

GhostGate registers that combination as an exact version, qualifies it against defined scenarios and policies, records the evidence, routes the decision to human reviewers, and issues a signed deployment attestation when approved.

If a material component changes, prior approval becomes invalid. The changed version returns to qualification instead of inheriting trust from an older release.

03 / Exact-version binding

The qualification record has a precise subject.

A release decision is only defensible when reviewers can identify the exact system that was assessed and detect when it changes.

REGISTER

Bind the manifest

Record code, configuration, model, prompts, tools, identities, permissions, policies, memory, data connections, and shared dependencies.

QUALIFY

Build the evidence

Measure behavior against scenarios and policy, establish Behavior DNA, trace RiskChains and blast paths, and compare fleet relationships.

ADMIT

Enforce the decision

Require human approval, express conditional controls, sign the attestation, validate it at admission, and invalidate it after material change.

04 / Qualification dimensions

Review the agent and the authority around it.

GhostGate evaluates more than task completion because consequential failures often emerge from interactions between behavior, access, and shared infrastructure.

01

Behavior

Establish Behavior DNA baselines, identify mutation and drift, detect exact recurrence, and preserve recurrence memory.

02

Permissions

Test allowed, denied, approval-bound, and conditional actions so release conditions reflect the authority the agent actually exercises.

03

Dependencies

Trace shared identities, services, data, models, and other dependencies that can widen the blast path beyond one version.

04

Policy

Qualify evidence against explicit policy packs and convert findings into controls that reviewers and admission systems can apply.

05

Causal risk

RiskChain analysis connects a behavior to its preconditions and consequences instead of presenting an isolated alert.

06

Fleet relationships

Cross-agent correlation and outbreak-cluster analysis reveal shared weaknesses, coordinated failures, and common causes across versions.

05 / Control after review

Approval remains conditional and reversible.

  • Human authority: reviewers decide whether a version is qualified, conditionally qualified, paused, failed back, or rejected.
  • Signed evidence: Ed25519 deployment attestations make the version and approval record independently verifiable.
  • Graduated response: controls can restrict, pause, contain, fail back, or require approval without treating every issue as identical.
  • Controlled re-entry: affected versions re-enter only after evidence, policy, and human review support the next decision.
  • Material-change invalidation: meaningful changes end the authority of the prior attestation and require a new qualification cycle.
